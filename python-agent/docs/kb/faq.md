# 领养常见问题

## 费用问题

平台不收取领养费。救助站可能收取已垫付的疫苗、驱虫、绝育成本，金额在宠物详情页公开，并提供票据。任何以“加急费”“选宠费”名义收取额外费用的行为都可以直接投诉。

## 学生可以领养吗

可以，但需要提供稳定经济来源证明，并说明毕业、搬家、寒暑假期间的宠物安置方案。未独立居住的学生必须取得共同居住人书面同意。

## 可以同时申请几只

最多同时保留 3 条待审核申请。建议优先选择最匹配的一只，避免占用多个救助站的沟通资源。

## 审核需要多久

志愿者通常在 48 小时内联系。若 3 个工作日没有收到回复，可以在“我的申请”中查看进度，或联系在线客服。

## 没有养宠经验可以领养吗

可以。首次养宠建议选择性格稳定、健康档案完整的成年猫犬，并在申请中说明愿意学习科学喂养知识。平台会提供新手养护清单。

## 领养后发现生病怎么办

领养后 7 天内发现的传染性疾病或先天性疾病，由原救助站承担首次诊疗费用。慢性病与意外伤害由领养人承担，平台可协助对接合作医院。

## 可以指定品种吗

可以按品种筛选，但是否有货取决于救助站当前情况。平台不建议指定花色或性别，性格匹配比外观更重要。

## 家人不同意怎么办

领养必须取得全部共同居住人同意。家人不同意的申请不会通过，建议先充分沟通，或等待家庭环境稳定后再申请。

## 异地可以领养吗

部分救助站支持异地领养，需要申请人自行承担运输费用并接受视频家访。跨省运输必须使用合规宠物托运，不接受快递寄送。

## 可以退养吗

可以，但必须联系原救助站，不得私自转送或遗弃。退养会被记录，频繁退养将影响后续领养资格。
