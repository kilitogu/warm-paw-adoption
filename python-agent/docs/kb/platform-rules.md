# 平台规则与用户协议

## 平台定位

暖爪是连接救助站、志愿者与领养家庭的公益信息平台，不繁育、不售卖宠物，不提供活体交易服务。

平台展示的宠物信息由合作救助站提供，健康档案与照片尽可能保持真实，但不替代执业兽医的诊断。

## 用户行为规范

禁止发布虚假领养信息、买卖宠物、诱导私下交易、骚扰志愿者、恶意占用申请名额。

禁止以领养名义收集他人信息、倒卖宠物、用于繁殖或实验。发现上述行为将永久封禁账号，并移交相关部门。

## 隐私保护

平台仅收集领养审核必需的信息，包括联系方式、居住情况与家庭成员意见。信息仅用于审核与回访，不向第三方出售。

用户可以在个人中心查看与修改资料，也可以申请注销账号。注销后历史申请记录会被匿名化保留，用于统计与纠纷追溯。

## 领养协议

领养成功后，领养人需签署电子协议，承诺科学喂养、按时免疫、绝育、不弃养、不转送，并配合回访。

协议同时约定：领养人承担宠物日常开销与医疗费用；救助站保留回访权；出现虐待、弃养时平台有权收回宠物。

## 投诉与纠纷

遇到虚假信息、诱导收费、虐待动物等情况，可以通过“消息通知”或客服邮箱投诉。平台在 3 个工作日内响应。

领养纠纷优先协商解决；协商不成的，可向当地动物保护组织或市场监管部门反映。涉及违法行为的，移交公安机关。

## 内容版权

平台内的宠物照片、救助故事与知识库内容归原作者或救助站所有。未经授权不得用于商业宣传、繁殖售卖或二次分发。

引用知识库内容时需注明来源“暖爪 · 智能宠物领养平台”。
